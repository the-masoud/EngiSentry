3. Run `ES_PLOTQA` and wait for normal command return.
4. Review the Results UI, three project-distance rows, findings/evidence, governance wording, and artifact paths.
5. Use `Open Output Folder` only if needed.
6. Do not save a human review decision unless the case is explicitly designated for P8 review testing.
7. Close without saving.
